# Longevity+

Longevity+ is a dietitian and client management platform designed to
help dietitians manage clients, nutrition plans, progress, memberships,
payments, appointments, and meal adherence.

## Features

- Client registration and authentication
- Dietitian dashboard
- Client profile management
- Structured diet plan builder
- Sections and meal options
- Meal quantities and instructions
- Food photo logging
- Dietitian meal adherence review
- Progress tracking
- Membership management
- Payment tracking
- Appointment management
- Notifications
- Client feedback and reviews

## Technology Stack

- Python
- Django
- SQLite
- HTML5
- CSS3
- Bootstrap
- JavaScript

## User Roles

### Dietitian
- Manage clients
- Create and manage diet plans
- Review food logs
- Track client progress
- Manage memberships and payments
- Manage appointments

### Client
- View assigned diet plan
- View prescribed meal quantities
- Upload meal photos
- Add notes
- View dietitian feedback
- Track progress
- View memberships and appointments

## Food Photo Logging

Clients can upload one photo for a complete meal/section after eating.

The food log records:
- Meal/section
- Prescribed foods
- Prescribed quantities
- Client photo
- Upload time
- Client note
- Dietitian review
- Dietitian feedback

Client-facing nutrition information does not display calories or macronutrients.
